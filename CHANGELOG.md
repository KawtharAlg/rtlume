# Changelog

## 0.1.0-rc.1 — 2026-10-27

- Added a dependency-free Node.js CLI.
- Added CSS, document, locale, and design-token analyzers.
- Added confidence classification and policy ownership.
- Added terminal, JSON, and SARIF output.
- Added auditable suppression comments.
- Added path traversal, symbolic-link, file-count, file-size, control-character, and evidence-redaction safeguards.
- Added English and Arabic examples plus automated tests.
- Added a Claude plugin skill package for local interpretation of results.

This is the first public release candidate. The npm package has not been published.
