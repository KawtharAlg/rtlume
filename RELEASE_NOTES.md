RTLume 0.1.0-rc.1

This first release checks CSS direction, document metadata, locale placeholders, and design tokens. It runs locally and returns text, JSON, or SARIF.

The regression suite covers malformed inputs, workspace boundaries, report writing, placeholder changes, and common false positives. CI tests Node.js 20, 22, and 24 on Linux, Windows, and macOS before publishing this release.

Start with the README examples. Results marked review need a person to check them. Static checks do not establish visual RTL quality, translation quality, or accessibility compliance. This is a release candidate; feedback and reproducible bug reports are welcome.

The npm package and Claude Directory listing have not been published.
