# RTLume

RTLume يكشف مشاكل RTL والترجمة قبل وصولها إلى الإنتاج. يفحص CSS وHTML وملفات اللغات وDesign Tokens، ثم يوضح الفريق المسؤول عن كل نتيجة.

`0.1.0-rc.1` هو أول إصدار تجريبي عام. يعمل محلياً دون إرسال الكود أو البيانات إلى أي خدمة خارجية.

## التشغيل

يتطلب Node.js 20 أو أحدث:

```bash
node ./bin/rtlume.js scan examples --config rtlume.config.example.json
node --test
```

يدعم الإخراج النصي وJSON وSARIF. النتيجة المصنفة `certain` قابلة للإثبات من الكود أو السياسة. `probable` تحتاج تأكيد السياق. `review` لا يجوز اعتبارها خطأ مؤكداً قبل مراجعة بشرية ببيانات عربية حقيقية.

## ما الذي لا يثبته؟

RTLume لا يقيّم جودة الصياغة العربية، ولا يجري اختباراً بصرياً، ولا يمنح شهادة WCAG أو DGA. الفحص الآلي جزء من ضمان الجودة وليس بديلاً عن اختبار المستخدم والمراجعة التصميمية والتقنية.
